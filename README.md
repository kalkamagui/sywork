# 한부모가족 지원 상담 도우미 (2026)

한부모가족 지원 전화상담과 자격·급여 모의판정을 돕는 브라우저용 도구입니다. 「2026년 한부모가족지원사업 안내」(성평등가족부) 기준으로 계산합니다.

## 사용 방법
- **PC에서 바로 열기:** 저장소를 내려받아 `index.html`을 더블클릭하면 브라우저(Chrome·Edge)로 열립니다. 서버나 설치는 필요 없습니다.
- **웹에서 열기:** GitHub Pages를 켜면 https://kalkamagui.github.io/sywork/ 에서 바로 쓸 수 있습니다(아래 "게시").

상담·판정 화면은 인터넷 없이 동작합니다. 인터넷이 필요한 것은 참고자료 탭의 성평등가족부 누리집 내용 불러오기, 그 탭의 PDF 저장, 보험개발원 차량기준가액 조회 페이지 열기뿐입니다.

## 입력 내용 저장
입력한 내용은 외부로 전송되지 않지만, 다음에 이어서 작업할 수 있도록 **이 브라우저 안(localStorage)에 자동 저장**되어 창을 닫았다 열어도 남아 있습니다. 웹 주소로 쓸 때도 같으며, 서버에는 아무것도 저장되지 않습니다.

- 공용 PC이거나 상담을 마쳤으면, 다시 열었을 때 나오는 안내의 [새로 시작]을 누르거나 [초기화]로 내용을 지우세요.
- [파일로 저장]을 누르면 상담 내용을 .json 파일로 내려받아 나중에 [불러오기]로 복원할 수 있습니다.
- 보험개발원 가액 조회 창은 조회 한도 확인용으로 가액을 넣은 날짜만 기록합니다(차량가액은 기록하지 않음).

## 화면 구성
왼쪽 메뉴는 "상담 메뉴"와 "참고 자료"로 나뉩니다.

| 메뉴 | 용도 |
|---|---|
| 자주 묻는 질문 | 전화상담 Q&A (키워드 검색·분류, 답변마다 지침 쪽수) |
| 전화상담 | 통화 중 대략 금액으로 "30초 사전 확인". 자동차는 용도·배기량·차령·가액·승차정원으로 재산 제외 / 일반재산 4.17% / 100% 환산을 바로 표시하고, 보험개발원 차량기준가액 조회 창(조회 한도 1일 5회·월 10회·연 20회 안내)에서 찾은 가액을 넣을 수 있음. 결과는 자격·급여 판정으로 넘겨 이어서 입력 |
| 자격·급여 판정 | 소득·재산 신고서 항목대로 입력 → 대상 유형, 가구원수, 소득인정액, 받을 급여·금액, 계산 근거 |
| 신청 안내 | 판정 결과에 맞춘 신청 장소·준비서류 체크리스트·절차·고지사항 (인쇄/PDF 저장) |
| 참고 자료 | 아이돌봄지원사업, 한부모가족 자녀양육 지원, 청소년 한부모 아동양육 및 자립지원 (누리집 내용 불러오기, PDF 저장) |
| 2026 핵심 숫자 | 기준 중위소득·선정기준·급여 단가 등 요약 (오른쪽에서 열리는 창) |

## 파일
- `js/rules2026.js` — 기준 중위소득, 선정기준, 급여 단가, 공제·환산율 등 **지침 수치 전부**. 연도가 바뀌면 이 파일만 고치면 됩니다.
- `js/calculator.js` — 소득인정액 계산과 판정 로직
- `js/faq.js` — 전화상담 Q&A (답변마다 지침 쪽수 표기)
- `js/app.js`, `css/style.css` — 화면
- `tests/calculator.test.js` — 계산 로직 테스트. 수치나 판정 로직을 고친 뒤 `node tests/calculator.test.js`로 확인
- `.claude/launch.json` — 개발 확인용 미리보기 설정(사용에는 필요 없음)
- `LICENSE` — GNU GPL 3.0 전문

## 개발·게시
- **테스트:** [Node.js](https://nodejs.org)가 있으면 저장소 폴더에서 `node tests/calculator.test.js`를 실행합니다. 추가 설치는 필요 없습니다. 지침 수치(`js/rules2026.js`)나 판정 로직을 고친 뒤 모두 통과하는지 확인하세요.
- **로컬 미리보기:** `index.html`을 바로 열어도 되고, `python -m http.server 8765`로 띄운 뒤 http://localhost:8765 에서 열 수도 있습니다.
- **GitHub Pages 게시:** 저장소 **Settings → Pages**에서 Source를 "Deploy from a branch", 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다. 이후 `main`에 푸시하면 1~2분 안에 웹 주소에 반영됩니다. 무료 계정은 저장소가 공개여야 Pages를 쓸 수 있고, 게시된 사이트는 주소를 아는 누구나 열 수 있습니다.

## 계산 범위와 한계
- 근거: 「2026년 한부모가족지원사업 안내」(성평등가족부). 소득인정액 = 소득평가액 + 재산의 소득환산액.
- 모의계산입니다. 실제 선정은 사회보장정보시스템 공적자료 조회·조사로 결정됩니다.
- 사적이전소득: 매월 받는 정기 지원·양육비(각 12회로 셈)와 최근 1년 달마다 받은 비정기 지원을 합쳐, 달마다 기준중위소득 15%를 넘는 금액의 1년 합계 ÷ 12를 반영합니다. 1년 중 6회 미만이면 반영하지 않되, 그 합계가 중위 50%를 넘으면 넘는 금액만 반영합니다. 지원 횟수(건)는 직접 입력할 수 있고, 비우면 매월 받는 정기 지원·양육비를 각각 12회로 세고 비정기 지원은 금액이 있는 달마다 1회로 셉니다(한 달에 여러 번 받았으면 직접 입력). 사용처가 확인된 일시 지원(임대보증금 마련·수술비 등)의 제외 여부는 입력하는 사람이 판단합니다.
- 자동차: 재산 제외(장애인사용·생업용)·일반재산 환산 요건과 가구별 보유 한도(일반가구 생업용 1 + 일반재산 1, 장애인가구 장애인사용 1 + 생업용 또는 일반재산 1)를 화면 입력값으로 판정합니다. 전방조종자동차, 질병·부상으로 소유가 불가피한 차, 압류·멸실·불법명의·처분 예정 차 등 담당자 확인이나 지방생활보장위원회 심의가 필요한 예외는 반영하지 않습니다.
- 장기금융저축공제: 3년 이상 가입 장기저축 잔액과 공제 시작 연도로 누적 한도(연 500만원 × 경과 연수, 총 1,500만원)를 계산합니다. 실제로는 연도별 적립 변동분과 이월 한도로 관리하므로, 해마다 적립액이 다르면 담당자 확인이 필요합니다.
- 임대보증금 부채: 여러 채 보유 시 한 채분만 인정합니다(2026 개정). 어느 한 채를 인정할지는 화면에서 고르지 않으므로 인정받는 한 채의 보증금을 입력합니다. 2025.12.31 기준 여러 채를 인정받은 기존 수급자는 2026년 기준월까지 2채째부터도 인정합니다.
- 대학생 등록금 지출 공제(학기 등록금 ÷ 6)와 주택·농지연금(월 수령액 50% 공제, 누적액은 부채)을 반영합니다. 등록금 공제 대상(34세 이하·1년 이내 휴학)과 이미 공제한 학기인지는 입력하는 사람이 확인합니다.
- 기타 산정되는 재산: 처분·증여 가액에서 확인된 사용액과 자연적 소비금액(기준 중위소득 50% × 경과 개월)을 뺀 나머지를 반영합니다. 차감액은 금융재산 처분분부터 적용하며, 실제 배분과 증빙 인정 여부는 조사 단계에서 정해집니다.
- 재산범위 특례: 근로무능력 가구·처분 곤란 재산은 순재산·금융재산 기준과 100% 환산 자동차 여부로 판정하고, 위원회 의결 제외 재산은 입력한 금액을 일반재산에서 먼저 뺍니다. 근로무능력 여부와 처분 곤란 사유는 화면에서 판정하지 않습니다.
- 7인 이상 가구는 지침 표에 기준액이 없어 "담당자 확인"으로 표시됩니다. 사적이전소득 제외 기준(중위 15%·50%)과 처분 재산의 자연적 소비금액은 6인 기준 중위소득으로 계산하고 경고를 띄웁니다.
- 자립지원 별도가구 특례(취·창업 자녀)는 18~34세 자녀에만 적용하고(22세 미만 취학 자녀 포함), 월 90만원 이상 소득 여부는 입력하는 사람이 확인합니다.
