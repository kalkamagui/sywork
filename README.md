# 한부모가족 지원 상담 도우미 (2026)

`index.html`을 더블클릭해 브라우저(Chrome·Edge)로 열면 됩니다. 서버나 설치는 필요 없고, 인터넷 연결도 쓰지 않습니다. 입력한 개인정보는 어디에도 저장되지 않으므로 창을 닫으면 사라집니다.

## 화면 구성
| 탭 | 용도 |
|---|---|
| ① 전화상담 | 통화 중 대략 금액으로 "30초 사전 확인", 자주 묻는 질문(키워드 검색·분류), 2026년 핵심 숫자 |
| ② 자격·급여 판정 | 소득·재산 신고서 항목대로 입력 → 대상 유형, 가구원수, 소득인정액, 받을 급여·금액, 계산 근거 |
| ③ 신청 안내 | 판정 결과에 맞춘 신청 장소·준비서류 체크리스트·절차·고지사항 (인쇄/PDF 저장) |

## 파일
- `js/rules2026.js` — 기준 중위소득, 선정기준, 급여 단가, 공제·환산율 등 **지침 수치 전부**. 연도가 바뀌면 이 파일만 고치면 됩니다.
- `js/calculator.js` — 소득인정액 계산과 판정 로직
- `js/faq.js` — 전화상담 Q&A (답변마다 지침 쪽수 표기)
- `js/app.js`, `css/style.css` — 화면
- `.claude/launch.json` — 개발 확인용 미리보기 설정(사용에는 필요 없음)

## 계산 범위와 한계
- 근거: 「2026년 한부모가족지원사업 안내」(여성가족부). 소득인정액 = 소득평가액 + 재산의 소득환산액.
- 모의계산입니다. 실제 선정은 사회보장정보시스템 공적자료 조회·조사로 결정됩니다.
- 단순화한 부분: 정기 사적이전소득은 기준중위소득 15% 제외 후 반영, 양육비 수령액은 전액 반영(보수적), 자동차는 생업용·장애인용·일반재산 환산 요건을 화면 입력값으로 판정, 기타 산정되는 재산(최근 처분 재산)과 재산범위 특례는 미반영.
- 7인 이상 가구는 지침 표에 기준액이 없어 "담당자 확인"으로 표시됩니다.
